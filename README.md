# Выборы мэра Goxten — 2026

Одностраничный сайт голосования для ролевого проекта на Minecraft-сервере.
Чистый HTML + CSS + JS, без фреймворков и без сборки — подходит для GitHub Pages как есть.

## Файлы

```
index.html    разметка страницы
styles.css    оформление, светлая и тёмная тема
script.js     партии, расписание, валидация, отправка в Discord
.nojekyll     чтобы GitHub Pages не обрабатывал файлы Jekyll
```

## Публикация на GitHub Pages

1. Создайте на GitHub пустой публичный репозиторий, например `goxten-vote`.
2. В папке с этими файлами выполните:

   ```bash
   git init
   git add .
   git commit -m "Выборы мэра Goxten 2026"
   git branch -M main
   git remote add origin https://github.com/ВАШ-ЛОГИН/goxten-vote.git
   git push -u origin main
   ```

3. В репозитории откройте **Settings → Pages**.
4. В блоке **Build and deployment** выберите источник **Deploy from a branch**,
   ветку `main` и папку `/ (root)`. Нажмите **Save**.
5. Через минуту-две сайт будет доступен по адресу
   `https://ВАШ-ЛОГИН.github.io/goxten-vote/`.

Обновление сайта — обычный `git push`: страница пересобирается сама.

## Настройка

Всё, что нужно менять, лежит в начале `script.js`, в блоке `НАСТРОЙКИ`.

| Константа         | Что задаёт                                                       |
|-------------------|------------------------------------------------------------------|
| `WEBHOOK_URL`     | Discord-вебхук, куда уходят голоса и служебные сообщения          |
| `VOTING_WINDOWS`  | Расписание: окна, внутри которых принимаются бюллетени            |
| `TEST_MODE`       | `true` — участки открыты всегда, расписание игнорируется          |
| `ADMIN_NAMES`     | ФИО председателя ЦИК — открывает панель ЦИК вместо голоса         |
| `PARTIES`         | Список партий                                                     |
| `PASSPORT_MIN`    | Минимальная длина игрового паспорта                               |

### Расписание

```js
const VOTING_WINDOWS = [
  { start: '2026-09-21T08:00:00+03:00', end: '2026-09-21T21:00:00+03:00' },
  { start: '2026-09-23T08:00:00+03:00', end: '2026-09-23T23:59:00+03:00' }
];
```

Участки открыты только внутри этих окон, между ними сайт показывает «Перерыв
между турами», после последнего — «Голосование завершено». Добавить тур —
дописать строку, убрать — удалить. `+03:00` это московское время; у игрока в
другом часовом поясе всё пересчитается само.

Чтобы проверить голосование до 21 сентября, поставьте `TEST_MODE = true` —
участки откроются сразу, а в шапке появится пометка «Тестовый режим».
Перед выборами обязательно верните `false`.

### Добавить партию

Допишите объект в массив `PARTIES` — карточка, строка в бюллетене, номер и
счётчик «партий в бюллетене» появятся автоматически:

```js
{
  id: 'newparty',
  name: 'Название партии',
  short: 'NP',
  tag: 'Пометка',
  program: ['Первый пункт', 'Второй пункт'],
  note: null,
  color: '#1D4E8F',      // цвет для светлой темы и полосы в Discord
  colorDark: '#7CADE8'   // цвет для тёмной темы
}
```

### Панель ЦИК

Если ввести в бюллетень ФИО из `ADMIN_NAMES` — в любом порядке полей и любом
регистре — голос не засчитывается: в Discord уходит запрос «Начинать
голосование?», а на странице открывается панель ЦИК.

Приём бюллетеней при этом управляется только расписанием. Кнопки в панели
объявляют открытие и закрытие в Discord-канале, но сами ничего не включают —
чтобы сдвинуть сроки, правьте `VOTING_WINDOWS`.

### Кеш браузера

`index.html` подключает файлы как `styles.css?v=3` и `script.js?v=3`. После
правки этих файлов увеличьте номер (`?v=4` и так далее), иначе браузеры, уже
заходившие на сайт, покажут старую версию.

## Что нужно знать перед публикацией

- **Вебхук будет виден всем.** Сайт статический: ссылка на вебхук лежит в
  `script.js`, который любой может открыть. Если начнётся спам — удалите вебхук
  в настройках Discord-канала и создайте новый, затем замените `WEBHOOK_URL`.
  То же касается ФИО из `ADMIN_NAMES` и выключателя голосования: на публичном
  репозитории это не секреты.
- **Discord не умеет отвечать статичному сайту.** Кнопки в сообщении вебхука
  работать не будут — для этого нужен бот с обработчиком interactions. Поэтому
  подтверждение старта сделано на самой странице.
- **Повторное голосование блокируется в браузере.** Отпечаток паспорта хранится
  в `localStorage`, поэтому с другого устройства или в режиме инкогнито можно
  проголосовать ещё раз. Настоящая защита требует сервера — Discord-лог помогает
  заметить дубли вручную.

Чтобы убрать первые два ограничения, вебхук прячут за прокси: например,
бесплатный Cloudflare Worker, который принимает голос со страницы и сам
пересылает его в Discord. Тогда в коде сайта остаётся только адрес прокси.
